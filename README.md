# brandonsweeting.com

Personal academic website of Brandon Sweeting. Plain HTML and CSS, no build step.

- `index.html`, `highlights.html`, `research.html`, `publications.html`, `teaching.html`, `outreach.html`: the six pages (each shares the same header and footer)
- `css/site.css`: all styles, with light and dark color tokens at the top
- `images/`: headshot and favicon
- `uploads/curriculum_vitae.pdf`: the downloadable CV
- `netlify.toml`, `_redirects`: Netlify deployment and redirects from the old site's URLs

To preview locally, open `index.html` in a browser.
